# Change Log

All notable changes to the "quicklyzer" extension will be documented in this file.

## [1.0.0]

### Added
*   **Initial Release:** Launched the Quicklyzer VS Code extension.
*   **Sidebar Integration:** Added a custom Activity Bar view with a one-click "Analyze Project" action.
*   **Intelligence Dashboard:** Implemented a full-screen, native-themed webview UI for displaying analysis results.
*   **Core Metrics:** Integrated local analysis for Architecture, Performance, Testing, API, Build, Dependencies, Documentation, and Security.
*   **AI Assessment:** Added project grading, maturity calculation, and AI-driven verdicts (Strengths, Weaknesses, Recommendations).
*   **State Management:** Added professional loading and error states for seamless UI flow.
*   **Offline Support:** Packaged the core CLI analysis engine directly into the extension bundle via `esbuild` for zero-configuration        portability.
